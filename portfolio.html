PROJECTS

NOISE REDUCTION IN AUDIO SIGNALS

Designed and implemented a noise reduction system for audio signals using Python, NumPy, and SciPy. Applied a Butterworth bandpass filter (300 Hz – 3400 Hz) to remove unwanted noise while preserving essential speech frequencies. Visualized both time-domain waveforms and power spectra using Matplotlib to compare noisy and filtered signals. Converted the processed audio back to WAV format and saved it for further analysis. Integrated SoundDevice to play both original and filtered audio, allowing real-time quality assessment. The code successfully reduces noise in an audio file by applying a bandpass filter, which limits frequencies to a specified range. By plotting both the waveform and power spectrum of the original and filtered signals, the code provides a clear view of how the bandpass filter impacts the audio data.
